📌 DSP 中小客户流失原因调研（53份严口径样本）

  • 81.1% 流失客户因「投流效果不及预期」流失，51.2% 反映人群不精准
  • 近一个月流失客户中 25% 表示愿意再试试，近三个月仅 6%——时间越长越难挽回
  • 流失前典型信号：消耗突然飙升/瞬间消耗完→零转化→停投→流失

📌 快影临沂线下调研（33位万粉创作者）

📌 快影：三类垂类创作者的动机差异

  • 游戏/二次元作者（17位，52%）：兴趣驱动/为爱发电，追求内容新奇有趣，有模仿学习新功能的动力。但变现少且不稳定
  • 三农作者（8位，24%）：以扩大农产品销路为核心目标，看重成交转化率而非播放量。剪辑能力弱、进阶意愿低
  • 美食团购/电商作者（8位，24%）：对变现有明确预期，内容生产成本低，对会员价格不敏感、付费意愿高
  • AI已在万粉作者中建立初步认知（33位中有24位了解AI，14位已使用过，2位已实现AI变现）

📌 同城相亲：线上型 vs 线下型作者的变现逻辑差异

  • 线上型：直播为主（日均5-7小时），靠打赏/刷礼物变现。平台即撮合场所，变现路径单一且被动
  • 线下型：短视频获客，靠登记费（男600/女300元）和成功后答谢红包（3000-6000元/对）变现。变现路径更清晰
  • 站内近六成作者做相亲超2年，但仅44%成功撮合20对以上——撮合效率有巨大提升空间

📌 聚星达人：低粉 vs 高粉达人的内容创作动机

  • 低粉段达人（10w-）：追求短期变现→会尝试不同行业，多用AI产出脚本，对AI短剧解说参与意愿高（4/6）
  • 高粉段达人（10w+）：关注账号垂直度→选择与账号定位匹配的商单，会软广化呈现，用豆包/DeepSeek做参考和润色
  • 高粉段中「变现型」对AI脚本功能需求强（可大量生产）vs 「创作型」认为AI文案太硬广不适合账号风格

📌 DSP 中小客户：效果层面的沉默痛点

  • 假人/假粉："投了500块，抖音来的都是真人，快手投来的打电话也不接"
  • 线索质量差：线索不精准、重复线索、打通后用户表示误触/没兴趣
  • 获客成本高："一个下单用户能接受70块，它一个成本大概500块"
  • 瞬间消耗："几分钟内突然消耗没了"、"直播间没上人，钱扣完了"
  • 起量难："跑一天只消耗几毛钱，就是不跑量"

📌 快影：18项体验优化问题

  • 音频相关（6项）：AI克隆音色效果不好（付费且不如网页工具）、智能配音缺乏情绪（太生硬）、搜不到想要的音效、iOS找不到音频文件夹等
  • 常规剪辑（6项）：删除片尾麻烦、画中画功能位置靠后、素材拖拽体验不佳、文字快剪跳变衔接生硬等

  • 封面制作（2项）：封面制作麻烦
  • 功能层级复杂、常用功能位置深，增加创作成本

📌 快影 vs 剪映 & PR

  • 剪映和PR已在专业作者群中建立极高认同——"剪映就是一个傻瓜式的操作非常简单，谁都拒绝不了"
  • 剪映的付费化（语音转字幕收费、热门素材收费）导致部分作者考虑回流快影
  • 但快影的付转免策略触达严重不足：33位作者中仅1人知晓快影近期免费策略
  • PC端市场：剪映PR心智极强，快影切入需优先解决场景缺失、迁移成本高等前置问题

📌 DSP客户心智："投流效果差"→"不值得再试"

  • 流失后时间越长，心智越固化。近三个月流失的客户仅6%愿意再试（vs 近一个月25%）
  • 69.8%的流失客户回流顾虑是「之前投放效果不好」——不是产品功能问题，是信任崩塌
  • "花了一万，没有成交的"——经历了高成本零回报后形成「DSP没用」的固化认知

📌 快影作者心智："免费工具不值得付" vs "付费=投资"

  • 无稳定变现的作者："免费就够用了，收费就换"——价格敏感+工具可替代
  • 有变现能力的作者："本身你要挣钱就得投入这个，多少钱无所谓"——付费是创作投资
  • 「挣钱才值得投入工具」vs「投入工具才能挣钱」——两种心智决定了是否愿意为剪辑工具付费

📌 同城相亲作者心智："平台是撮合场所" vs "平台是获客渠道"

  • 线上型：平台=撮合场所——依赖实时互动完成匹配，一切在直播间内闭环

  • 两种心智决定了作者对平台扶持的需求：线上型需要流量和直播工具，线下型需要精准获客和信任背书

阶段触点我们做什么用户感受
触达期 社群邀请 / 外呼 / 线下访谈 BP客诉信号→主动联系→说明来意和激励 "有人在乎我的感受"
参与期 深度访谈 / 社群讨论 结构化提问→挖掘真实动机→记录行为模式 "终于有人问我想什么了"
反馈期 看板更新 / 结论同步 输出分析结果→同步BP→验证假设 "上次说完的东西真的被改了"
验证期 波动监控 / 留人策略 看数据验证→效果是否有改善→迭代 （不感知）
留存期 长期社群 / 专属顾问 持续跟进行为变化→预警+主动服务 "一直在，随时能找到"
